      Jak oznaczać powierzchnie styku

      1. Wybierz kość z listy po lewej (albo PgUp / PgDn).
      2. Obracaj prawym przyciskiem myszy i znajdź przełom.
      3. Różdżka: kliknij przełom - zaznaczy obszar aż do ostrej krawędzi. Za dużo? Ctrl+Z i zmniejsz tolerancję.
      4. Pędzel / Gumka: popraw brzegi lewym przyciskiem.
      5. Drugi przełom na tej samej kości = Nowa powierzchnia (każda ma swój kolor).
      6. Ctrl+S zapisuje do contacts/<kość>.json. Przy zmianie kości zapis jest automatyczny.
      Lewy przyciskmaluj / zaznacz
      Prawy przyciskobracaj
      Środkowy / Shift + prawyprzesuwaj
      Kółkoprzybliż / oddal
      B E Wpędzel / gumka / różdżka
      [ ]mniejszy / większy pędzel (lub tolerancja różdżki)
      1…9, Nwybór powierzchni, nowa powierzchnia
      Ctrl+Z Ctrl+Ycofnij / ponów
      R F Creset widoku / druga strona / kolory skanera
